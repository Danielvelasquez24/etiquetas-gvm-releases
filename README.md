# Etiquetas GVM — releases

Aquí solo se publican los ejecutables (`Etiquetas GVM.exe`). El programa revisa este repositorio al abrir y con el botón ⬆️ se actualiza solo.

No descargues de aquí a mano salvo para la primera instalación: copia el .exe junto a tu carpeta de etiquetas (no borres config_etiquetas.json, listas_precios.json, plantillas_etiquetas\ ni logos\).
